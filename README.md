# Metasense-RE

This repository contains my implementations for **Question 1** and **Question 2** of the Metasense Research Engineer screening challenge.

## Repository Structure

- `Task 1/` – Implementation and supporting material for Question 1.
- `Task 2/` – Low-compute ECG artefact identification using an unsupervised, feature-based approach for Question 2.

Each task directory contains its own `README.md` with instructions for running the implementation and additional details.
